\section{Proposed WealthGenie Platform}

WealthGenie is a web-based financial literacy and decision support platform implemented as a monorepo with a React 18 frontend, a Node.js and Express REST backend, Supabase authentication and PostgreSQL persistence, and Python-based dataset processing pipelines. The platform is designed for Indian beginners and operates exclusively in Indian Rupees with en-IN number formatting.

The platform's five core modules form a coordinated learning pipeline. A user begins with the Learn module, which provides structured financial literacy content. The user then completes the Assessment module to profile their financial situation. Based on this profile, the recommendation engine provides risk-aware investment guidance in the Explore Investments module. The user may then experiment with simulated trades in the Paper Trading module and examine hypothetical financial scenarios in the Digital Twin module. Each module consumes the output of the preceding one, so the platform progresses the user from understanding concepts to assessing their position, exploring suitable investments, experimenting with simulated decisions and comparing hypothetical outcomes.

The backend exposes REST endpoints for learning content and progress, financial assessment, recommendation generation, paper trading operations, scenario management and AI narration. The frontend renders each module as a dedicated page within a single-page application. The recommendation engine is the platform's central technical component and is described in detail in Section VI.

The platform enforces strict data integrity principles. All market data used by the recommendation engine is sourced from verified AMFI and NSE Indices datasets, with provenance metadata recorded for every source. No fabricated historical charts, mock returns or imputed values are presented. Where data is missing, the engine reports the absence explicitly and applies neutral scoring rather than penalizing or rewarding the gap.
